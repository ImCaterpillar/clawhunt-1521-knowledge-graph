# 实现说明 — #1521 知识图谱子域

## 需求还原

企业知识库与多 Agent 协作系统（系列 50 单）的拆单之一。本单范围：
**在高价值业务子域建立实体、关系与证据引用**。

验收标准：**提供匿名图谱样例及关系查询验证**。

## 设计

### 1. 实体 / 关系双 schema

`schema/entity.schema.json`：
- `entity_id`（唯一，`ent-` 前缀）
- `name` / `type`（person/org/system/process/document/knowledge_entry/
  domain/project 枚举）
- `evidence_refs`（证据引用，≥1，可回链）

`schema/relation.schema.json`：
- `source` / `target`（实体 ID）
- `relation`（9 种枚举：employs/uses/depends_on/implements/manages/
  references/part_of/produces/reviewed_by）
- `evidence_refs`（≥1）

### 2. 三类关系查询（对应验收"关系查询验证"）

| 查询 | 方法 | 说明 |
|---|---|---|
| 直接关系 | `direct(source, relation=None)` | 实体的直接出边，可按关系类型过滤 |
| 多跳路径 | `path(start, end, max_depth=4)` | BFS 找 start→end 的路径 |
| 证据回溯 | `evidence(entity_id)` | 返回实体的证据引用，可回链来源 |

测试覆盖：直接关系（测试 2）、按类型过滤（测试 3）、多跳路径
（测试 4）、证据回溯（测试 5）。

### 3. 完整性与校验

- `add_entity` / `add_relation` 前置校验 schema；
- 关系端点必须已存在（未知端点抛 GraphError，测试 6b）；
- 非法实体/关系类型被拒（测试 6）。

### 4. 匿名合规

样例全部为脱敏/合成数据（企业 Agent 系统系列交付物本身已脱敏，
无真实客户/机密），符合"只能使用获授权或脱敏资料"。
